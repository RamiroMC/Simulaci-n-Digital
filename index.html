Generadores de números pseudoaleatorios

Dos algoritmos propios, uno congruencial y otro no congruencial, con detección automática de ciclo: en cuanto un valor se repite, la generación se detiene y se avisa a partir de qué punto la secuencia empezaría a repetirse.

Regla común a ambos generadores

Ningún generador de este tipo es infinito: todo algoritmo determinístico basado en una semilla entra tarde o temprano en un ciclo, porque el conjunto de valores posibles es finito. Por eso, cada vez que se genera un número nuevo, el programa revisa si ese valor ya había aparecido antes. Si aparece una repetición, detiene la secuencia ahí mismo y reporta en qué posición ocurrió y cuántos números se alcanzaron a generar sin repetirse (el periodo).

Generador congruencial lineal

X(i+1) = (a·X(i) + c) mod m

Reglas del algoritmo

Propuesto por D. H. Lehmer. Parte de una semilla X0 y aplica siempre la misma fórmula recursiva:

  1. Se elige una semilla entera X0 (0 ≤ X0 < m).
  2. Se calcula X(i+1) = (a·X(i) + c) mod m.
  3. El número pseudoaleatorio en (0,1) es r(i) = X(i) / (m − 1).
  4. Se repite el paso 2 hasta juntar los n valores pedidos o hasta que un X(i) se repita.

Para que el ciclo sea lo más largo posible (periodo máximo = m) se exige que m sea potencia de 2, que a ≡ 1 (mod 4) y que c sea impar. Las tres variables a, c y m no están fijas: se piden explícitamente abajo, y el programa te dice si con los valores que escribiste el periodo máximo queda garantizado.

iX(i)r(i)

Generador de cuadrados medios

Von Neumann, década de 1940 — no congruencial

Reglas del algoritmo

No usa una fórmula lineal; en su lugar, cada número se obtiene elevando el anterior al cuadrado y quedándose con los dígitos del centro:

  1. Se elige una semilla X0 con D dígitos.
  2. Se calcula Y(i) = X(i)² y se toman sus D dígitos centrales; si el cuadrado tiene menos de D dígitos, se completa con ceros a la izquierda.
  3. X(i+1) son los D dígitos centrales de Y(i).
  4. r(i) = 0.[D dígitos centrales].
  5. Se repite hasta juntar los n valores pedidos, hasta que se repita un valor, o hasta que el resultado degenere en 0 (algo que le puede pasar a este método y que también se reporta).

Este método no funciona sin una semilla: toda la secuencia parte de X0.

iX(i)r(i)
